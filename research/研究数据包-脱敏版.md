## 四、行动状态机模式（从实测归纳）

**PvE 战斗**：选择目标 → 前置检查（体力/次数/等级）→ 服务器自动结算 → 战报（胜负+奖励）→ 状态更新
- 失败不扣次数的情况存在（部分玩法"战败提前结束"），消耗型（体力）失败也消耗 ★

**报名/赛季类**：报名（日期窗口）→ 服务器排期 → 定时结算 → 领取奖励
- 例：武林大会每日报名；掠夺周二报名周三领胜负奖；踢馆周五试炼周六领奖 ☆

**抽奖类**：免费次数判断 → 抽取 → 随机奖励（颜色分级）→ 次数-1
- 例：邪神秘宝/神魔转盘/深渊秘宝/娃娃机/幸运转盘均每日免费 1 次 ★

**领取类**：每日 1 次 → 领取 → 直接入账（登录礼、活跃礼包、周周礼包等）★

**兑换类**：余额/积分检查 → 选择兑换项 → 扣资源 → 入账
- 例：竞技场河图洛书每日 10 个；帮派商会兑换 ★

**成长类**：材料收集 → 强化/合成 → 成功或失败提示
- 奥义/神装/星盘/器魂/神魔录均为"自动兑换强化"模式 ☆

**资源流（定性）**：
- 体力（上限 100）：乐斗/BOSS 战消耗，随时间恢复 ★
- 活力（上限 50）：历练/反向乐斗消耗 ★
- 阅历：战斗/任务产出，成长消耗 ★
- 材料三态：直接消耗型（药水/香炉）、积累兑换型（碎片→整物）、强化型（强化书/玄铁令）★

**每日产出节奏**：免费抽奖 N 个 → 每日领取类 N 个 → 战斗/任务产出 → 兑换消耗。
研究价值：观察"哪些入口每天固定给资源、哪些是随机的、哪些是付费钩子"。

## 六、差分实验方法论与样例

**方法（对应"前后快照差分"）**：
```
1. 快照 before（只读：角色属性/背包/入口）
2. 执行单次玩法（选免费、无消耗）
3. 快照 after（只读）
4. 对比 before/after：资源变化、入口变化、页面文本变化
5. 记录：输入（目标/次数/前置）→ 输出（资源/掉落/经验/状态/失败提示）
```

**样例记录（2026-08-20，免费任务验证，无副作用）**：
```
任务: 幸运金蛋（当天已领取）
before: 等级86(73401/118350) 体力93/100 活力1/50 斗豆74 斗币4940 鹅币0 活跃度55
执行: 脚本自动判断已领取 → 跳过
after : 全部字段无变化
结论: 重复执行不重复结算（幂等）★
```

**待积累样本**（每日重置后）：
- 邪神秘宝免费抽 ×N → 奖励分布（颜色等级频率）
- 每日领取类 → 固定产出值
- 乐斗一次 → 体力-？经验+？的精确数值

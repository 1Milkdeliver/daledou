## 一、早期版伤害公式（★贴吧技术帖，2012 年，版本分离）

### 1.1 伤害计算帖（1422151177，2012-2-21）

```
主动方理论伤害 = 武器伤害(上限~下限) × 力量系数 × 技能加成 × 魂珠加成 × 所处状态 × 帮派技能
最终伤害 = 主动方理论伤害 - 被动方防御伤害
```

| 系数 | 数值 |
| --- | --- |
| 力量系数 | ≈ 力量属性值 / 10 |
| 武器好手 | 武器伤害 +20% |
| 惯用重物 | 大件武器伤害 +10% |
| 避重就轻 | 中小型武器伤害 +15% |
| 帅魂 | 暴击时 ×1.5 |
| 剑魂 | 按等级增加攻击力 |
| 状态：怒 | +50% |
| 状态：残影 | +30% |
| 帮派技能：天马 | +100% |
| 帮派技能：会心一击 | +50% |
| 帮派技能：化骨绵掌 | 会心基础上再 +50% |
| 武器自身暴击 | 无帅魂也可产生 1.5 倍暴击 |

**防御方**：霸气/情比金坚/皮糙肉厚（可叠加）。**暴击忽略皮糙肉厚和帮修，但不忽略情比金坚和霸气**。

**实例（锁魂藤，力量40，武器好手+避重就轻）**：
```
理论 = (35-40) × 4 × 1.2 × 1.15 = 193-220
皮糙肉厚(-30%) → 减 58-66
实际 = 135-154
```

### 1.2 力量与伤害解析帖（1395957750，2012-2-2）

```
{力量 + 武器(上限~下限) × 武器好手加成 × 剑魂加成} × (2/5~2) × 暴击 → 减伤 = 最终伤害
```

- **浮动系数（2/5~2）**：统计稳定值（10000 次攻击近 1000 次达上限 2，非暴击所致）。
- **力量性价比**：力量+1 → 伤害+2/5~2（硬提升）。力量 20→40 伤害翻倍。
- **暴击 ×1.5**（早期版本）。

> ⚠️ 帖内评论质疑（天地飞仙2）：早期结论有争议，"伤害根据取整规则，剑君魂因取整最不稳定"。早期数据帖需谨慎对待。

## 二、当前版穿透/减伤机制（★腾讯频道入手指南，2026，当前版本）

### 2.1 穿透/减伤公式（核心机制）

```
穿透差 = 己方穿透 - 对手抗穿
按穿透差削弱对手的减伤值和减伤百分比
```

- 例：对手减伤值 400 / 减伤 80%，穿透差 50% → 减伤被削弱到 200 / 40%。
- **穿透超过 100% → 无视一切减伤**。
- 抗穿透同理（削弱对手穿透）。
- 例：42抗穿 + 队长50抗穿 = 92%，对手 130 穿透，130-92=38% → 削弱 38% 减伤效果。

### 2.2 属性机制（优先级速度>力量>生命>敏捷）

| 属性 | 机制 |
| --- | --- |
| 速度 | 先出手、出手回合更多，胜率高（速度为王） |
| 力量 | **不加成投掷武器伤害**，不影响其他武器/技能伤害（除非武技与力量关联） |
| 敏捷 | 加成闪避 + 投掷武器伤害，**300 敏捷达减伤上限** |
| 生命 | 均衡即可，正常比战力高 |

> **关键**：力量不加成投掷武器 → 解释实测"投掷武器伤害最低（436）"。

### 2.3 武器类型选择

大型/中型/小型/投掷，选一种发展。发展穿透、武器伤害、爆伤、命中。
必中武器：判官笔（小型）、蛇影弓（中型）、狂魔镰（大型）、可乐（投掷）。

## 五、关键结论

1. **版本差异**：早期版暴击 ×1.5（2012）vs 当前版暴击 ≈3.4x（实测）——**数值已大幅调整**，早期公式只能参考机制结构，不能用于当前版本数值。
2. **当前版核心伤害机制 = 穿透/减伤**：穿透差削弱减伤，100%穿透无视减伤。这是换皮开发战斗公式的核心参考。
3. **属性定位**：速度（先手）> 力量（不加成投掷）> 生命 > 敏捷（300上限），投掷武器天然弱势。
4. **佣兵数值**：满级 50-390% 不等，战斗/防御/状态三类，补充了佣兵图鉴的数值维度。

## 五·b、穿透/减伤/韧性机制深挖（★贴吧 7645729606+8025491376，当前版本 2021-2022）

### 穿透/减伤公式（★贴吧 7645729606）

```
伤害计算 ≈ 原伤害 × (1 + 武器伤害加成Y% - 减伤百分比R%)
0穿透 vs 100%减伤 → 伤害为 0（无论武器伤害多少）
100%穿透 → 无视一切减伤和格挡（该打多少打多少）
```

### 净穿透阈值（★实测总结）

| 净穿透（武器穿透-抗穿） | 效果 |
| --- | --- |
| >50 | 基本正常伤害 |
| ~30 | 伤害 1000-2000（触发格挡时 0-500） |
| <30 | 不破防，0 伤害 |
| 理想配置 | 主穿 180 / 大抗 110+ |

### 格挡机制

- 格挡技能 ≈ 增加 10-20 抗穿（情比金坚 > 神魔录 > 霸气护体）
- **100 净穿透无视一切格挡**（格挡=盾，先破盾再算本体伤害）

### 韧性/忽略机制（★贴吧 8025491376，2022）

```
对面武器忽略概率 = 武器原本忽略概率 + 对方抗韧性 - 我方相应武器韧性
净穿透 = 我方武器穿透 - 对方抗穿（削弱对应对应武器类型的减伤）
```

### 减伤百分比获取来源（★完整清单）

神饰10阶+18%、皮糙肉厚满级+30%、300敏捷(满级身手敏捷)+20%、问鼎华山+5%、星盘2技能+8%、仙武孔雀满级+16%、封印(4类武器祭坛5星)+5%+x%、投掷祭坛满级+15%+y%、神将组合技百鬼众魅+10%。

### 力量伤害公式（★帖内补充）

```
力量 × 基础伤害 × 0.2
基础伤害 = 武器面板伤害范围（元婴仙化有基础伤害增加）
```

### 变强路线优先级（★帖内结论）

```
速度 > 穿透 > 抗穿透 > 奥义 > 爆伤 > 技能韧性 > 抗爆伤 > 力量 > 武器伤害比 >
武器抗伤害比 > 武器韧性 > 武器伤害 > 武器伤害减免 > 生命 > 敏捷 > 命中闪避
```

## 五·c、早期战力公式（★贴吧 1176551399，2011，版本分离）

```
战力 ≈ 武器+主动技能累加（>15个按15个折算）+ 潜心+0.5/次 + 血量×0.05/点
```
> 早期（2011）战力只算武器+技能+潜心+血量，与当前版 41 条成长线完全不同，仅供理解战力系统演化，不用于当前版本。

## 六、对换皮开发的迁移建议

1. **伤害公式结构**（当前版）：`最终伤害 = (武器×加成×暴击) 经穿透差削弱的减伤` —— 建议换皮采用"穿透差→减伤削弱"模型而非简单减法。
2. **属性设计**：明确"速度=先手、力量=攻击(限武器类型)、敏捷=闪避+投掷"的分工，避免属性重叠。
3. **必中武器**：部分武器带"必中"特性（无视闪避），是装备设计的差异化点。
4. **佣兵数值**：按 1级→满级（如 130%→320%）设计成长曲线。

# R0 早期版本 · 战斗契约（R0_combat_contract）

> 早期（2010-2012）逐回合战斗顺序。来源：伤害计算帖(1422151177, 2012-02-21)、武器效果详解(1408291049, 2012-02-11)、知识大全(1176569910, 2011-08-15)、早期版本数据.md。
> ⚠️ 仅早期版本逻辑，**未从当前版战报推断早期数值**；倍率/数值以同版本来源为准，缺证据标 unknown。

## 一、逐回合顺序（★结构级，源自伤害计算帖+武器效果详解）

```
1. 先手判定      速度（快人一步/速度属性）决定谁先出手
2. 出手选择      攻击方选择 出武器 或 用技能（武器/技能抽取）
3. 命中判定      攻击方命中 vs 防守方闪避（凌波微步/身手敏捷/铁铲等）
4. 暴击判定      暴击率（帅帅魂珠等）；早期暴击 ≈ ×1.5
5. 减伤结算      防守方减伤：霸气护体/情比金坚/皮糙肉厚（可叠加）
                 ★暴击忽略皮糙肉厚和帮修，但不忽略情比金坚和霸气
6. 特殊效果      连击/忽略回合/反击/装死/带毒/吸血/瞬杀（见武器0-5星效果）
7. 伤害&HP更新   最终伤害 = 主动方理论伤害 - 防守方减伤
```

## 二、伤害公式（★伤害计算帖 2012）

```
主动方理论伤害 = 武器伤害(上限~下限) × 力量系数 × 技能加成 × 魂珠加成 × 所处状态 × 帮派技能
最终伤害 = 主动方理论伤害 - 被动方防御伤害
```

| 系数 | 数值 |
| --- | --- |
| 力量系数 | ≈ 力量属性值 / 10 |
| 武器好手 | 武器伤害 +20% |
| 惯用重物 | 大件武器伤害 +10% |
| 避重就轻 | 中小型武器伤害 +15% |
| 帅魂 | 暴击时 ×1.5 |
| 剑魂 | 按等级增加攻击力 |
| 状态：怒 | +50% |
| 状态：残影 | +30% |
| 帮派技能：天马 | +100% |
| 帮派技能：会心一击 | +50% |
| 帮派技能：化骨绵掌 | 会心基础上再 +50% |

> ⚠️ 以上为 2012 年玩家推导公式，数值级为早期版本，**不用于当前版**。力量系数/加成系数为玩家假设，置信度"中"。

## 三、效果结算细节（★武器效果详解 2012）

- **影响出手次数**：忽略回合/连击/休息一回合——会被技能抵消。
- **第二类效果**：闪避反击/攻击反击/暴击/投掷/必中/不会被反击/忽略装死/增闪避命中/无视大海/带毒/性别伤害/吸血/瞬杀。
- **带毒**：4星青龙戟20%持续2回合；5星50%持续5回合，不被装死抵消。
- **吸血**：7种鞭子（霹雳鞭/蚀骨鞭/混元金钩/锁魂藤/游龙惊鸿/仙人指路），可与嗜血叠加。
- **瞬杀**：5星小李飞刀（要你命三千）。
- **装死**：免死一次，生命1。

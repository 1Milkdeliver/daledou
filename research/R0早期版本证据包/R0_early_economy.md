## 二、来源-消耗闭环（★可确认的部分）

```
充值(Q币) → 体力药水 → 主动PK → 经验 → 升级 → 获得武器/技能
每天6次乐斗 → 元宝(10/天) → 社区消费
BOSS(菜菜/剑君/月敏) → 魂珠 → 武器入魂(3合1升级) → 增强武器
被动经验上限300(药水400) → 每日经验获取有上限
```

## 三、关键机制（★升级帖 2010）

- **被动经验上限**：被乐斗每天最多 300 经验（被动药水 400，神来拳套+药水 500）。
- **体力经济**：体力 = 主动行动的唯一资源，靠药水(5次/天) + 菜菜(2次/天) + 钻石加成补充。
- **武器保底**：5/10/15 级武器数 < 1/2/3 自动补一个（防脸黑）。
- **魂珠消耗**：3 合 1 升级；入 1 个 5 级魂需 120 个 1 级魂（早期版本数据.md）。

## 五、结论

早期经济闭环的核心是**体力驱动**（体力→PK→经验→升级→武器/技能）**+ 元宝小额奖励 + 魂珠养成**。货币体系比当前版简单（元宝/体力/Q币为主）。斗豆/斗币/卷轴的早期明细在公开素材中稀缺，标 unknown。

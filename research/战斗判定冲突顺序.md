# 战斗判定冲突顺序：命中/闪避/先手/暴击与特殊效果（2026-08-28）

> 交付 Codex P0 任务：命中、闪避、先手、暴击与特殊效果的**冲突/优先级顺序**。
> 来源：R0_combat_contract(早期,2012) + 数值结算技术贴汇总(当前版穿透/减伤/韧性) + 结算机制实测。版本分离标注。
> 用途：换皮开发**服务端权威结算**的判定顺序核心参考。

## 一、完整判定顺序（★综合早期+当前版结构）

```
1. 先手判定      速度决定谁先出手（速度为王）；先手方先发动攻击/效果
2. 出手选择      攻击方 出武器 或 用技能
3. 命中判定      攻击方命中 vs 防守方闪避（命中率 vs 闪避率）
                 ★必中武器无视闪避（判官笔/蛇影弓/狂魔镰/可乐）
4. 暴击判定      命中后判定暴击（暴击率）；早期×1.5 / 当前≈3.4x
5. 穿透/减伤     穿透差(己穿透-对手抗穿)削弱减伤；100%穿透无视一切减伤
6. 格挡判定      先破盾再算本体伤害；100%穿透无视格挡
7. 特殊效果      连击/忽略回合/反击/装死/带毒/吸血/瞬杀（伤害后结算）
8. 伤害&HP更新   最终伤害 = 主动理论伤害(经穿透/减伤/暴击) - 防御
```

## 二、冲突优先级规则（★关键）

| 冲突点 | 优先级规则 | 来源 |
| --- | --- | --- |
| **先手 vs 特殊效果** | 先手方先出手，先触发攻击/效果 | 早期+当前 |
| **命中 vs 闪避** | 命中判定先于闪避；闪避成功→攻击无效；**必中武器无视闪避** | 早期+当前 |
| **暴击 vs 命中/闪避** | 暴击在命中/闪避**之后**判定（未命中/被闪避则无暴击） | 早期 |
| **暴击 vs 减伤** | 暴击忽略皮糙肉厚/帮修，**不忽略**情比金坚/霸气 | 早期2012 |
| **穿透 vs 减伤** | 穿透差削弱减伤；100%穿透无视一切减伤 | 当前 |
| **穿透 vs 格挡** | 先破盾(格挡)再算本体伤害；100%穿透无视格挡 | 当前 |
| **韧性 vs 忽略** | 对面忽略概率 = 武器忽略 + 对方抗韧 - 我方韧性 | 当前 |
| **忽略 vs 装死** | 忽略装死效果（红缨枪5星）→ 装死失效 | 早期 |
| **带毒 vs 装死** | 带毒**不被装死抵消**（青龙戟5星50%持续5回合） | 早期 |
| **瞬杀 vs 减伤** | 瞬杀(小李飞刀5星)一击必杀，无视减伤/装死 | 早期 |

## 三、特殊效果结算分类（★武器效果详解）

- **影响出手次数**（在出手判定层）：忽略回合/连击/休息——会被技能抵消
- **第二类效果**（伤害结算后）：闪避反击/攻击反击/暴击/投掷/必中/不会被反击/忽略装死/增闪避命中/无视大海/带毒/性别伤害/吸血/瞬杀

## 四、当前版战斗公式（★迁移参考）

```python
伤害 ≈ 原伤害 × (1 + 武器伤害加成Y% - 减伤百分比R%)   # 经穿透差削弱
净穿透 >50正常 / ~30伤害1000-2000 / <30不破防0伤害
理想配置: 主穿180 / 大抗110+
暴击倍率 ≈ 3.4x（实测估值）
```

## 五、对换皮开发的判定顺序建议

1. **结算层序**：先手→命中→暴击→穿透/减伤→格挡→特殊效果→HP
2. **冲突解决原则**：命中/闪避决定攻击是否生效；暴击/穿透决定伤害大小；特殊效果在伤害后独立结算
3. **必中武器**（无视闪避）与**瞬杀**（无视减伤/装死）是差异化设计点
4. **版本差异**：早期暴击1.5x vs 当前3.4x——换皮数值自定，结构用当前版（穿透模型）

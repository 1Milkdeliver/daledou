# Hermes（DSH）接手手册：daledou 运行 + 研究产出

> **给未来 Hermes 会话的启动文档**：每次新会话开始时，先读本文件 + `研究数据包-脱敏版.md`，
> 即可接续本项目的日常运行与游戏机制研究，并把结论按协议交给 Codex。
>
> 更新时间：2026-08-25

---

## 一、这是什么

Q宠大乐斗（腾讯 QQ 网页游戏）的**日常/周常任务自动化脚本** + **游戏机制研究工具链**。

- 原理：直接请求游戏**文字版接口**（无浏览器），`cmd=index&style=1` 拿首页 → 按注册任务执行
- 你的职责：**运行维护 + 研究产出**（用户已把运行/开发交给 Hermes）
- Codex 的职责：消费你的研究结论，用于**原创桌宠游戏**设计（不是乐斗换皮）
- 仓库：本地运行版（含 cookie/日志）+ GitHub 开源版（脱敏）并存

## 二、日常运行（每会话开始确认）

| 项 | 位置/命令 |
|---|---|
| 项目目录 | 当前工作目录（daledou） |
| 运行 | `uv run main.py noon` / `evening` / `uv run main.py <模块>.<任务>` |
| 查看帮助 | `uv run main.py -h` |
| 今日日志 | `log/<账号QQ>/<日期>.log` |
| Cookie | `config/dld_cookie.yaml`（⚠️ 本地凭证，禁止外传/打印） |

**定时任务已配置**（Windows 任务计划程序，schtasks 查询 `daledou-*`）：
- 06:05 快照基线 → 06:06 免费实验 → 06:10 午间主流程 → 06:40 战报 → 06:50 晚间收尾
- 08:00-23:00 每小时监控（活动检测+免费领取）
- 09:00 上游订阅（upstream=gaoyuanqi，自动 rebase 合并）

> 服务器每日 **06:00 重置**。所有每日任务已提前到刷新后立即执行。
> 活跃度礼包由监控在活跃度达标后自动补领，不需要手动干预。

## 三、研究产出模式（核心协议）

### 数据来源（只读优先）
| 工具 | 用途 |
|---|---|
| `research/snapshot.py` | 只读状态快照（角色/体力/活力/入口） |
| `research/diff.py` | 快照前后差分 |
| `research/battle_reports.py` | 战报归档（仅归档已发生战斗，绝不触发战斗） |
| `research/experiment.py` | 免费差分实验（只选免费任务） |
| `research/monitor_claims.py` | 活动监控 + 免费领取 |

**红线**：绝不执行消耗体力/活力的实验、绝不主动触发战斗、绝不扣费。

### 研究结论落点（已有文档体系）
| 文档 | 内容方向 |
|---|---|
| `数值公式研究报告.md` | 数值逆向（经验曲线/恢复速率/药水性价比 F1-F14） |
| `接口字典.md` | 接口参数与返回结构 |
| `数据结构与服务器层面研究.md` | 服务器数据契约、每日观测 |
| `活动模板对照表.md` | 活动抽象结构、入口免费性 |
| `任务时间窗口与货币表.md` | 四资源账本 |
| `研究数据包-脱敏版.md` | **对外安全摘要（唯一可外传）** |

### 8 字段交接格式（每个结论必须带齐）
```
研究问题 / 来源范围与日期 / 观察量 / 证据等级（★实测☆推断）
可复用结构 / 不可迁移内容 / 待验证项 / 建议规则表字段
```

### 交接队列（DSH → Codex 缓冲）
- 文件：`research/交接队列.md`
- 每轮研究结论**追加一行**：`| 日期 | 主题 | 落点文档（章节） | [NEW] |`
- 状态：`[NEW]`（待 Codex 消费）→ `[已处理]`（Codex 吸收后改，**DSH 不改**）
- Codex 每次会话启动读此文件处理 `[NEW]` 条目

## 四、给 Codex 的交接流程（每次产出后）

1. 研究完成 → 写/更新对应 `research/*.md`（8 字段格式）
2. 追加到 `research/交接队列.md`（状态 `[NEW]`）
3. `git add -A && git commit`（commit 信息注明研究主题）
4. 推送到 origin（用户的开源仓库同步）

## 五、安全红线（必须遵守）

1. **Cookie/账号**：`config/dld_cookie.yaml`、`log/`、`情报汇总.md` 含账号信息 → 只本地，不入库、不打印
2. **脱敏**：对外只传 `研究数据包-脱敏版.md`；任何文档不得含 QQ号/本地路径/cookie/接口参数
3. **扣费**：不执行任何可能扣鹅币/斗豆/斗币的操作
4. **实验**：只做免费、无消耗实验；观察≠触发战斗

## 六、与上游的关系

- `origin` = 用户的开源仓库（1Milkdeliver/daledou）
- `upstream` = gaoyuanqi/daledou（上游原始项目，停更中）
- 09:00 自动拉上游 → rebase 合并本地增强 → 推回 origin
- 冲突时：保留本地增强，手动/AI 处理，绝不自动覆盖

## 七、常见运维（用户可能随时让做）

- **查运行情况**：读 `log/<账号QQ>/` 今日日志，汇总成功/失败/产出
- **新活动**：按 README"核心机制"写任务（注册名=首页链接文本），单任务测试后提交
- **任务失效**：抓首页分析是下架/改版/接口变化
- **Cookie 失效**：提示用户重新登录抓取（README 有三种方式）

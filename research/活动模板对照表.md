## 二、活动抽象结构（DSH 交接 · 任务2，2026-08-21）

> 研究问题：从活动模板中抽取「短行动 / 安稳推进 / 章节里程碑 / 收藏目标」的抽象结构，
> 供原创桌宠设计复用；筛除固定时段、日常税与连续登录压力。

**来源范围与日期**：本文件（135 任务归类）+ `任务时间窗口与货币表.md`（32 条节奏），2026-08-21。
**观察量**：6 类模板 × 各活动实例；代码静态归类样本（非行为数据）。
**证据等级**：代码注释 + 接口模式归类（静态推断）。

**四类抽象结构（已筛除固定时段/日常税/连续登录）**：

| 抽象类别 | 结构 | 触发→行动→结算 | 原版实例（仅结构参考） |
| --- | --- | --- | --- |
| 短行动 | 单次轻选择，几十秒闭环 | 免费机会→随机结果→耗尽；自动PvE→结算→战报 | 邪神秘宝 / 历练 |
| 安稳推进 | 无风险积累，可随时中断 | 每日领取→入账→次日刷新（无惩罚） | 每日奖励 / 周周礼包 |
| 章节里程碑 | 跨会话积累→一次性达成 | 连续目标 N 次→达成→奖励（允许中断补救） | 许愿 3 天 |
| 收藏目标 | 永久资产收集 | 材料/代币→指定制作→永久入藏 | 徽章 / 成就 / 名人堂 |

**可复用抽象结构**：
1. 短行动 = 状态卡 → 单次行动 → 结算卡 → 可见变化（核心循环最小单元）
2. 安稳推进 = 零风险、可中断、不惩罚回访（替代日常税的正面激励）
3. 章节里程碑 = 累计进度条 + 可补救（中断不重置已积累部分）
4. 收藏目标 = 永久资产 + 指定制作（非随机抽取，避免被动消费）

**不可迁移内容**：固定时段活动（周X / 1~25号）、连续登录奖励/惩罚、日常税式活跃度、原版活动名称与奖励池。

**待验证项**：
- 短行动目标时长（原版单次服务端 12s → 原创应 ≤30s 客户端闭环）
- 里程碑「可补救」具体规则（中断保留进度 vs 部分回退）

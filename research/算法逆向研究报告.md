## 一、战斗算法（逆向进度：结构级 ★，公式级 ⬜）

### 1.1 回合结构（★ 来自 9 回合完整战报）

```
回合 1: 雷霆一击（先手技能）→ 对手 HP-114（HP余 49999889）
回合 2: 炮拳 → HP-397
回合 3: 暴击 土豪金(小型武器) → HP-490
回合 4: 对手攻击 → 我方闪避
回合 6: 暴击 真·金砖(中型武器) → HP-978
回合 7: 封穴(降对手连击) + 暴击 幻影枪 → HP-837
回合 8: 封穴 + 暴击 五雷轰顶(中型武器) → HP-1067
回合 9: 无影手 + 暴击 狂魔镰(大型武器) → HP-979
```

**观测到的机制**：
- 每回合单次行动，玩家/对手交替或按先手规则触发（回合 4 对手攻击被闪避）
- **技能可叠层**：封穴（debuff，不直接伤害）+ 武器攻击同时发生
- **暴击触发词固定**（"凝神摒气触发暴击"），暴击时武器名不同（小型/中型/大型轮换）
- 对手为 BOSS 时 HP 约 5000 万（49999889 → 满血推测 5000 万，☆）

### 1.2 伤害统计（★ 单场战斗 7 次有效伤害，需多样本）

| 指标 | 值 | 说明 |
| --- | --- | --- |
| 普攻伤害 | 114 / 397（avg 255.5） | 含先手技能、炮拳 |
| 暴击伤害 | 490~1067（avg 870.2） | 5 次样本 |
| 暴击倍率 | ≈3.4x（样本粗糙） | **需 ≥30 样本验证** ⬜ |
| 武器相关 | 小型/中型/大型武器伤害梯度 | 978(中型) vs 979(大型) 接近，待验证 ⬜ |

**假设**（⬜ 待多样本回归）：伤害 = 攻击基准 × 技能倍率 × 暴击倍率 × 随机浮动 ±X%；
武器类型影响基准或倍率；封穴降低对手连击概率（无伤害但改变节奏）。

### 1.3 确定性/随机性分层（★ 已确认）

同一场战斗（机制签名相同：HP 序列 114/397/490/978/837/1067/979 完全一致）多次查看，
**叙事文案每次随机变化**（"空手疾向中路"vs"大喝一声炮拳"、"舞得呼呼风声"vs"蓄势待发"）。
→ 结论：**战斗结算完全确定，叙事层独立随机**。这是逆向战斗公式的最大便利：
多场战斗可直接比较数值而不被文案干扰。

## 二、成长算法（逆向进度：参数结构 ★，曲线拟合 ⬜）

### 2.1 已观测参数（★ 来自强化/成长页）

| 系统 | 观测参数 | 推断逻辑 |
| --- | --- | --- |
| 武器升级 | 短剑4级：伤害+6连击+50%，需卷轴5，成功率**低(不降级)**；判官笔3级：需卷轴60，成功率**必成** | 成功率分级（必成/低/中/高）+ 等级越高卷轴需求激增（5→60） |
| 铁匠铺 | 匠心0星，战力0.6，进度0/20，每次+2点，耗百炼钢*1(库存275) | 线性进度：10 次升级/星（20/2） |
| 神魔录 | 0阶1级，祝福值0/20，消耗神魔残卷*1，祝福值永久有效 | **保底机制**：失败积累祝福值，20 满必成 |
| 佣兵 | 碎片 0/150、1/150…（各佣兵需求不同） | 碎片收集线：150 碎片=1 佣兵 |
| 星石 | 2级迅捷石速度+2、2级日曜石固定伤害+3、3级紫黑玉… | 等级×属性线性加成 |
| 经验曲线 | 86级(73401/118350)；斗神塔 2经验/层、10/20层 6经验；画卷 19~29经验 | 每级需求随等级增长（73401/118350 需多日快照拟合） |

### 2.2 成长公式假设 ⬜

- 经验曲线：exp_needed(level) 随等级增长，86 级时单级需求 118350（样本点）
  → 用 06:05 + 22:00 每日快照采集 (等级, 经验) 序列，回归拟合（多项式/分段）
- 战斗力 = Σ(装备+武器+星石+神魔录+佣兵+铁匠…)，字段分散在各页
  → 用"单项操作前后战力差分"逐项归因（实验设计）

### 2.3 设计启示（给桌宠游戏）

- 成功率分级（必成→低）+ 不降级 = 低挫败感赌成长；配合保底（祝福值）= 可规划
- 材料债真实存在（卷轴 5→60、碎片 150）：MVP 只保留一条深度成长线

## 六、已验证结论汇总（可直接进设计）

1. **战斗 = 确定性结算 + 随机叙事**（最强结论，直接支持"服务器算清楚、AI 讲精彩"）
2. **成长 = 成功率分级 + 保底祝福值 + 碎片收集**（三种防挫败/防无底洞设计并存）
3. **经济 = 多币种隔离 + 每日固定产出 + 幂等守卫**
4. **节奏 = 6:00 重置 + 每日次数/体力双闸门**
5. **入口 = 首页聚合网络**（165 入口 → 桌宠 MVP 砍到 4 块）
